# BlogVerse - 3D Blog Landing Page

A stunning, modern 3D design landing page for a blog web application featuring immersive animations, interactive elements, and responsive design.

## ✨ Features

- **3D Animations**: Floating cubes, rotating spheres, and interactive 3D elements
- **Modern Design**: Clean, contemporary UI with gradient backgrounds and glassmorphism effects
- **Responsive Layout**: Optimized for all device sizes from mobile to desktop
- **Interactive Elements**: Hover effects, mouse tracking, and dynamic animations
- **Smooth Scrolling**: Seamless navigation with scroll-triggered animations
- **Performance Optimized**: Lightweight and fast-loading

## 🚀 Quick Start

### Prerequisites
- Node.js (v14 or higher)
- Modern web browser

### Installation & Running

1. **Clone or download the project**
2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```
   This will start a live server at `http://localhost:3000`

4. **Alternative - Simple server**:
   ```bash
   npm start
   ```

## 🔧 Customization

### Changing Colors
Update CSS custom properties in `styles.css`:
```css
:root {
    --primary-color: #your-color;
    --secondary-color: #your-color;
    /* ... */
}
```

### Modifying 3D Effects
Adjust animation parameters in `script.js`:
```javascript
// Change animation intensity
const intensity = (index + 1) * 10; // Modify multiplier
```

### Adding Content
Update the HTML content in `index.html` and corresponding styles.
